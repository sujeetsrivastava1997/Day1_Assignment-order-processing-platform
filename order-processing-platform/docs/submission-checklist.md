## Items that must be completed in the user's Azure/GitHub account

1. Create the GitHub repository and push this directory.
2. Create Azure resources with `terraform apply`.
3. Configure GitHub OIDC and repository variables/secrets.
4. Run the pipeline against `main`.
5. Capture Azure Cost Management screenshots.
6. Run the troubleshooting challenge and capture `kubectl` output.
7. Put the final GitHub repository URL into the submission form.
